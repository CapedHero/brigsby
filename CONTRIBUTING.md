# Contributing to Brigsby

The public `CapedHero/brigsby` repository accepts external pull requests and
publishes reviewed releases.

## Before opening a public pull request

1. Read the public repository's README and contribution guidance.
2. Make sure you have the right to contribute the change.
3. Submit the pull request under the Apache-2.0 contribution terms. Brigsby
   does not require DCO sign-off or a CLA/ECA at this stage.

Employer-owned, substantial, or legally uncertain contributions pause for
explicit maintainer authorization and counsel review. Do not put private
development instructions, experiments, benchmarks, or commercial material in
the public repository.

## Maintainer handling

Brigsby maintainers review accepted public changes and apply the project's
standard verification before including them in a later release. Contributors do
not need any special repository access to submit or discuss a public pull
request.
